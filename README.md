# B站直播间消息记录器

## 一、工具简介

本工具是基于Go（1.26.5）开发的B站直播间消息记录组件，可自动监控、实时抓取、留存直播间消息数据，支持多房间同时监控、定时任务调度；轻量化、可灵活嵌入各类二次开发项目，可在服务器上长期稳定运行；本体运行内存约10-15MB左右，单房间连接开销很小，理论可支持极高并发连接；实际使用时建议同时连接数30左右（对应自动监控配置60-80个活跃主播），以免触发风控（本程序运行必须配置B站账号的登录cookies！！！使用需注意cookies的时效性）。

## 二、运行前置

1. **配置文件要求**：需将程序配置文件放置在与 exe 可执行文件**同一根目录**下，否则自动监控、定时任务功能无法正常生效。

    - `schedule_config.json` 定时调度任务文件：存储定时任务配置（合法任务全部加载），格式[{"room_id": 22603245,"ts": [1788870000, 1788873600]}]，本地秒级时间戳数组，执行成功后程序会自动更新文件。

    - `up_info.jsonl`  自动监控配置文件：存储需要自动监控的UP的信息（全部加载），行格式 [uid(int), roomid(int), name(str)]，示例：[1265680561, 22603245, "永雏塔菲"]

2. **目录创建**：程序首次运行和记录消息时，会在exe所在目录自动生成日志文件和弹幕数据文件，无需手动创建：

    - `HHHH-MM-DD.log` 日志文件：存储程序运行日志、错误日志、运行状态记录

    - `danmaku` 弹幕数据文件夹：存储所有直播间的消息数据

3. **文件规则**：每类消息数据文件已CMD.jsonl形式存储,1000行轮转、可实时查看（非实时磁盘同步，可少量查看，不建议外置程序在运行时高频刷新文件）；程序持有每类消息轮转对应的最新文件，运行时该文件无法修改。

4. **注意事项**：请勿强制终止程序进程，强制退出可能会导致少量缓存数据丢失，建议使用内置退出命令（exit）正常退出。

## 三、目录结构

程序运行后自动生成的目录层级如下，数据分类清晰、便于统计查阅：

```Plain Text
程序根目录
├─ 程序.exe
├─ 配置文件             # schedule_config.json & up_info.jsonl
├─ HHHH-MM-DD.log/     # 日志目录
└─ danmaku/            # 弹幕数据根目录
   ├─ 房间号/         # 按直播间号分类
   │  ├─ HHHH-MM-DD/   # 按启动日期自动建文件夹（按CMD分类存储jsonl文件）
   │  └─ ...
   ├─ 房间号/
   └─ ...
```

## 四、功能使用

### 4\.1 手动操作模式

程序默认启动即为主动控制模式，支持手动添加、移除、查看监控房间，核心命令如下：

|命令格式|功能说明|终端输出提示|
|---|---|---|
|`start {room_id}`|启动监控指定B站直播间|已连接到 \{room\_id\}|
|`remove {room_id}`|断开并移除指定直播间监控|已移除房间 \{room\_id\}|
|`list`|查看当前所有正在监控的房间|在监控中的房间：\{room\_id\}\.\.\.，共 n 个|
|`exit`|程序正常终止|停止所有房间连接并保存缓存数据|
|`config cookies {cookies}`|B站登录cookies设置（必须）|可在运行时更新|

### 4\.2 配置监控模式

通过读取本地配置文件批量管理直播间，支持批量启动、重载配置，适合长期固定监控场景。

#### 切换模式命令

- 输入 `live check`：进入自动控制模式，终端前缀变为 `live check>`

- 输入 `back`：从自动模式退回主动手动控制模式

|命令格式|功能说明|
|---|---|
|`load`|读取本地配置文件|
|`start`|批量启动内存中加载的全部房间，终端输出对应房间号及自定义备注名|
|`stop`|停止当前所有正在监控的直播间，并终止该模块|
|`list`|查看自动模式下的监控房间总数及所有房间ID|
|`clear`|清理内存中的所有房间|

### 4\.3 定时任务功能

支持加载配置文件中的定时任务，自动过滤合法任务并执行，可实现定时启动/停止直播间监控，适配周期性数据统计场景。所有命令以 `timer` 为前缀。

|命令格式|功能说明|
|---|---|
|`timer start`|启动配置中所有合法定时任务（可用于重新加载任务和重启模块）|
|`timer stop`|停止所有正在运行的定时任务|
|`timer show`|展示当前待执行定时任务信息，展示格式：房间ID、执行时间（年-月-日 时-分-秒）|
